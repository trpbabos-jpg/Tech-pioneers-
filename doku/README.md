# Doku

- `abgabe_checkliste.md`: was für die Abgabe von Dokumentation und Projektbericht gefordert ist, was wir schon haben und was noch fehlt
- `aenderungsverlauf.md`: Projektprotokoll der Gruppe mit Übersicht (Datum, Wer, Zeit), Einträgen, offenen Punkten, Wiedervorlagen und Zeitaufwand. Grundlage für den Projektverlauf
- `messwerte.md`: Drehzahl, Geschwindigkeit, Bremsweg
- `testtabelle.md`: jeder Test mit Erwartung vorher und Ergebnis
- `mindmap_v1.pdf`: Mind Map vom Pitch (16.10.)
- `praesentationen/`: Folien jeder Präsentation als PDF, Dateiname mit Datum, z. B. `2026-10-16_pitch.pdf`
- `ECHO-Projektkarte.pdf`: Projektkarte mit Inbetriebnahme-Anleitung (Entwurf)
- `ECHO-Projektverlauf-Wochen.docx`: Dokumentation des Projektverlaufs nach Vorlage Kap. 7, Woche für Woche (Entwurf v0.6.0), `ECHO-Projektverlauf-Wochen.pdf` zum Lesen auf GitHub
- `ECHO-Projektergebnisse.docx`: Darstellung der Projektergebnisse nach Vorlage Kap. 7 mit Benutzer- und Entwicklerdokumentation, bestehenden Problemen und Weiterentwicklung (Entwurf v0.5.0), `ECHO-Projektergebnisse.pdf` zum Lesen auf GitHub
- `marketing/`: Comic-Cover (A3 hoch) und Comic-Strip (A3 quer)

Das persönliche Projekttagebuch führt jeder selbst und gibt es über Moodle ab.
