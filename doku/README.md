# Doku

- `aenderungsverlauf.md`: wichtigste Schritte und Entscheidungen mit Datum, Grundlage für den Projektverlauf
- `messwerte.md`: Drehzahl, Geschwindigkeit, Bremsweg
- `testtabelle.md`: jeder Test mit Erwartung vorher und Ergebnis
- `mindmap_v1.pdf`: Mind Map vom Pitch (16.10.)
- `praesentationen/`: Folien jeder Präsentation als PDF, Dateiname mit Datum, z. B. `2026-10-16_pitch.pdf`
- später: Projektkarte mit Inbetriebnahme, Dokumentation des Projektverlaufs, Darstellung der Projektergebnisse (Vorlagen Kap. 7)

Das persönliche Projekttagebuch führt jeder selbst und gibt es über Moodle ab.
